# Smart Recipe Generator

A web app that generates recipes with AI. Enter the ingredients you have (or a dish idea) and get a recipe with ingredients and steps.

Built with AI-assisted development (vibe coding) and the Google AI Studio API.

## Features
- Recipe generation from your input
- Simple, responsive single-page interface
- [Add any other feature you built, e.g. dietary options, servings]

## Tech stack
HTML, CSS, JavaScript · Google AI Studio API (Gemini)

## How to run
1. Download or clone this repository.
2. Create a free API key in Google AI Studio.
3. Open `Smart-Recipe-Generator.html` and replace `YOUR_API_KEY` with your key.
4. Open the file in your browser.
